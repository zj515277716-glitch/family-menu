### 1.1 意外发现详情：src/index.html 缺失

- 现象：H5 dev server 所有 HTML 路径均返回目录列表（serve-index），无页面。
- 根因：`apps/h5/src/index.html` **从未存在于仓库**（git 全历史确认）。Taro 4 的 `H5WebpackPlugin` 先检查该模板是否存在，不存在则**完全不注册任何 HTML 生成插件**，编译产物中没有任何 HTML。
- 修复：按 `@tarojs/cli@4.2.1` 官方模板补建该文件（标题「家庭菜谱」）。
- 验证：重启 dev server 后编译日志出现 `asset index.html 1.03 KiB [emitted]`；请求 `/` 返回 200 且含 `<div id="app">`。
