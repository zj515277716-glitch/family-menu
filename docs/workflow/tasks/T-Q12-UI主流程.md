## 需求

1. **S-04 定明天的餐（C-2）**：成人/儿童步进（默认带出长期设置 defaultAdults/defaultChildren）、必消食材标签（增删）、临时忌口（独立区标注「仅明天生效」）、想吃的菜（选填）、餐次勾选（早/中/晚，默认全选）。**同一次编辑会话内任何操作顺序不丢已填**（设计规则 5）；保存失败提示重试不丢已输入。
2. **S-05 生成中骨架**：点「推荐菜谱」先骨架屏「正在为明天搭配三餐…」再进三餐菜单。
3. **S-06 三餐菜单（C-3/C-3a）**：早餐/中餐/晚餐分区，每餐按人数+餐型出菜，缺槽留空如实标注不凑数（PD-018）；顶部必消横幅「✓ 必消食材已用上：xx」（未消耗如实标注）；想吃的菜与忌口/必消冲突时如实说明「想吃的 X 与忌口冲突，未排入」。三操作：某菜「换一道」（弹同餐型候选，原因可填可不填；候选共 0 个如实展示）、某餐「换一餐」（该餐整体重推，其他两餐不动）、「全部换一批」。按钮加载态后真替换；换后必消横幅、总时长同步更新；失败「没换成」原菜单保持可再试。**同一天重进看到同一份三餐不重新生成**。
4. **S-07 空手两型（C-7）**：如实说明哪一餐、什么原因（无菜型/时间型/组合冲突），给调整出路（放宽临时忌口/删必消/换想吃的菜）。
5. **S-08 采购清单+备菜建议（C-4）**：三餐食材合并去重一张清单；按（成人+儿童）换算凑整；必消标「已有」不删；常备调料不出现；「就按这个买」勾选随计划保存（刷新还在）；备菜建议分「今晚预处理」（泡/腌/解冻）与「明早先做」（早餐工序前置）。
6. **S-03 双区首页（C-5 展示部分）**：上半区今天三餐——按当前时间把「下一餐」置顶（6-10 点早餐在前，过 10 点中餐在前，依此类推），每餐显示评价标签（读已记录数据；「记一笔」按钮为入口占位，T-Q13 接通）；下半区「定明天的餐」入口。
7. **S-13 服务未连接**：网络/服务失败时叠加「⚠ 服务未连接」+「重试」，绝不显示假数据；请求封装统一出口，本卡各屏接好。
8. **三态覆盖**：每屏加载/空/错误（可重试）三态齐备（设计规则 4），按原型演示态落实。
