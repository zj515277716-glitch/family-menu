## 背景

TP-08 EMPTYFIX（39eeb0c6，已上线）修复"必消输入未确认被静默丢弃"（点推荐自动收进输入框文字）与食材别名（西蓝花等）等三连问题，线上 6 词实测出套餐。本卡为该用户流程补**正式回归测试**，并作为四角色闭环首个试点。纯测试任务，零业务逻辑改动。

## 目标（AC 逐条可判）

- **AC1** 新增/扩展 API 集成回归测试：必消食材「西红柿」「西蓝花」→ 推荐接口返回非空候选，且候选中存在包含该食材（按 name/aliases→ID 归一后）的套餐。断言用真实 HTTP/服务级调用（禁止 Mock）。
- **AC2** 空手/不可满足回归（对照 TP-02 证据口径）：不带必消调用推荐 → 200 且 candidates 非空、unmetMustUse 空/缺省；带「苦瓜」→ 200 + `candidates:[]` + `unmetMustUse` 含「苦瓜」且不建 Plan（无 Plan/Event 落库）。
- **AC3** 全部测试真实执行：命令 + 退出码 + 数字结果原文记录（如实，含失败项）。
- **AC4** 零业务逻辑改动；若测试暴露真实缺陷 → **停下报主控，不得顺手修**（修复走新卡，保持 WIP=1）。
