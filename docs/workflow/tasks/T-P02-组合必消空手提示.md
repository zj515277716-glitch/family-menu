## 背景

T-P01 实测（卡外发现#5）：必消「西红柿 西蓝花」时，每样单独都有菜能用上，但菜库里没有任何一桌菜能同时用上全部——接口返回 `candidates:[]` 且 `unmetMustUse:[]`。现版页面走通用文案「今晚没有找到合适的搭配」，用户不知道问题出在"组合"。产品裁决（PD-014）：加组合空手专用提示，纯前端判定（candidates 空 + unmetMustUse 空/缺省），不改契约/引擎/API。C-7 单食材空手行为不变。

## 目标（AC 逐条可判）

- **AC1 组合空手变体**：服务返回 `candidates=[]` 且 `unmetMustUse` 空/缺省、且今晚必消非空时，屏⑥空手卡显示 C-7a 文案：「西红柿、西蓝花这两样今晚凑不进同一桌菜——每样单独都能做，但没有一桌能同时用上它们」（食材名 = 今晚实际必消列表，顿号连接，动态生成；标题/正文如何拆分由实现定，句子语义须逐字符合 C-7a）；按钮「返回修改必消食材」（关闭空手卡回屏①，行为同现版）；不生成菜单、不改今晚设置。今晚必消为空的退化场景（无必消仍空手，罕见）保留现版通用文案兜底。
- **AC2 C-7 单食材空手不回归**：必消「苦瓜」→ 文案仍指名『没用上「苦瓜」』+「去掉「苦瓜」再试」按钮，与现版一致；unmetMustUse 非空（含多食材）分支的文案与按钮行为均不变。
- **AC3 UI 基准同步 + 零越界改动**：先同步 [e-final.html](../../../docs/ai-rebuild/ui/e-final.html) 屏⑥（在苦瓜变体旁补组合变体示例）与 [design-spec.md](../../../docs/ai-rebuild/ui/design-spec.md)（屏⑥说明与关键跳转行），再动 h5 代码；git diff 仅含允许范围文件，packages/shared、packages/engine、packages/list-merger、apps/api、apps/api/prisma 零改动（`git diff --stat` 可证）。
- **AC4 真实构建与回归证据**：h5 构建/类型检查 0 错（命令 + 退出码 + 数字结果原文）；现有回归 tests/tp01-mustuse-regression.cjs 全绿（本地 PG + API 真实执行，禁止 Mock）；未验证项必填。
