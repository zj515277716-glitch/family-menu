# T-Q05 真机体验卡（待生产发布后使用）

> 版本：以生产发布后的 `/health` 版本为准 ｜ 地址：https://menu.jijingkongjian.xin ｜ 建议 15~20 分钟
> 说明：这是「验收体验」，不是重新设计；请按下面顺序操作，遇到任何不顺手/看不懂/数据不对，截屏并记下页面与操作。

## 1. 进门与设置（约 3 分钟）

1. 手机浏览器打开地址，输入家庭口令；退出后重进应免输。
2. 进「设置」：改成人/儿童人数、时长档、家里的锅、菜系、忌口、避开窗口，保存后显示已保存；刷新重进值还在。

## 2. 定明天的餐 → 三餐菜单 → 采购清单（约 7 分钟）

1. 首页点「定明天的餐」：核对默认人数是否带出设置；加一个必消食材、一个临时忌口；选一道想吃的菜；餐次默认全选。
2. 点「推荐菜谱」：先看到骨架屏，再进三餐菜单。
3. 三餐菜单：核对必消横幅（用上/没排上都要如实）；试一次「换一道」（有候选/无候选都看）、一次「换一餐」、一次「全部换一批」；失败时应提示没换成且原菜单还在。
4. 点「确认三餐，查看采购清单」：核对合并去重、必消「已有」、常备调料不出现；勾两项再刷新，勾选还在；看「今晚预处理/明早先做」。

## 3. 第二天执行：首页 → 做法 → 记一笔（约 5 分钟）

1. 首页看今天三餐：下一餐是否置顶；每餐评价标签是否正确。
2. 点某道菜「看做法」：大图、菜名/餐次/人数、用料是否按人数缩放、分步做法、上一道/下一道是否正常。
3. 对某餐点「记一笔」：做了没/好吃吗/下次还做吗，耗时选填；提交后标签立即更新；同餐再记一次应覆盖。
4. 故意关掉弹层再打开，已选答案应还在（不会清空）。

## 4. 历史（约 3 分钟）

1. 历史 Tab：按日分组、每天三餐、四色标签；点菜名能复看做法。
2. 无记录时应看到「还没有记录」并能去定明天的餐。

## 5. 异常（约 2 分钟）

1. 飞行模式/断网打开首页：应明说「服务未连接」+ 重试，不出现假菜单；恢复后重试正常。
2. 必消填一个库里没有的食材生成：应如实说哪一餐出不来、为什么，并给调整出路。

## 记录方式

- 每个问题：截屏 + 页面名 + 操作 + 你期望看到什么。不要输入任何系统编号。
- 已知限制：菜品图为示意图占位；反馈草稿刷新页面不保留；历史只展示近 14 天；字号放大/弱网真机表现待你确认。
