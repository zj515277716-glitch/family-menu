评价四色：好吃=ok 绿 / 一般=mid 米灰 / 翻车=bad 暖红 / 没做=none 灰。硬禁忌一律 bad 红字并配「绝不会出现」说明（红线提示）。
标签/chips 一律「半透柔彩底（同色 ~10%）+ 1px 同色细边（inset ~26%）」，不用实色块；警示/硬禁忌细边加浓至 ~30% 保持辨识度。「下一餐」标签例外：主色渐变 + 柔和橙影浮起。

## 2. 版式规则（网格卡片式）

1. **菜品卡 `.fcard`**：上图下文，图 4:3 通宽卡顶（圆角上沿、object-fit cover），卡内只留菜名（15.5px 700）+ 1 行关键信息（13px 次色），操作收成卡底 40px 小按钮（如「换一道」）。
2. **双列网格 `.grid2`**：三餐菜单页菜品卡双列等宽，间距 12px。
3. **横滑卡片流 `.hscroll`**：首页「今天三餐」每餐区真实 overflow-x 横滑（卡宽 158px；明天摘要大卡 196px），scroll-snap 对齐，隐藏滚动条。
4. **清单屏**：分组标题右侧叠放 34px 小圆图 `.gthumbs` 点缀；勾选行 56px；必消标「已有」划线不删；常备调料不出现。
5. **表单**：白卡分区（一卡一事），标题 17px + 一行说明；选项统一胶囊 `.opt`（选中=主色浅底+描边）；chips 五色语义（必消绿/临时忌口警示/硬禁忌红/软偏好灰/添加虚线）。
6. **做法页（PD-016 方向 A）**：4:3 全出血大图为首 + 底部渐变遮罩压菜名/餐次/要点 chips（时长=主色热 chip）；左上 44px 圆形返回；「‹上一道｜下一道›」换道导航；用料按人数缩放成行（名左量右）；分步=序号圆点统一样式；底部固定操作栏。
7. **弹层**：底部圆角 16px 弹层（抓手条 + 居中标题），底层内容压暗不可点；「记一笔」按餐三问 + 耗时选填。
8. **三态**：每列表必有加载（骨架形状照抄真实布局）/ 空（一句结论+出路按钮）/ 错误（警示横幅+重试，绝不假数据）；演示页：S-05 加载、S-11 空、S-13 错误。
9. **图像**：一律 AI 示意图占位（assets/dishes/），每页保留「示意图·正式版为试做实拍」小字；正式版试做实拍（DEC-007 不变）。
10. **枚举全中文、时间本地格式**（「10月14日 周三」「约 18:00」），由公共函数格式化（实施时）。

## 4. NutUI 组件 ↔ 原型元素对照（实施用，nutui-react-taro 4.x）

| 原型元素 | NutUI 组件 | 备注 |
|---|---|---|
| 底部 3 Tab `.tabbar` | `Tabbar` + `Tabbar.Item` | reLaunch 切换清栈 |
| 主/次/弱按钮 `.btn/.btn-ghost/.btn-plain` | `Button`（type=primary / plain / default） | 主按钮每屏至多 1 个 |
| 卡底 40px 小按钮 `.fcard-act .mini` | `Button` size="small" | 每按钮必有反馈 |
| 状态/评价标签 `.tag-*` | `Tag` 自定义背景/字色 | 四色评价按 §1.1 |
| 菜品卡网格 `.grid2 .fcard` | CSS Grid + `Image` | 图 4:3 lazyload，失败降级 ph 暖色底 |
| 每餐区横滑 `.hscroll` | `ScrollView` scroll-x（Taro） | 不用 Swiper（卡宽不一） |
| 选项胶囊 `.opts/.opt` | `Radio.Group` / `Checkbox.Group` 定制胶囊 | 单选/多选按语义 |
| 必消/忌口 chips | `Tag` closeable 或自绘+`×` | 五色语义按 §2.5 |
| 步进器 `.stepper` | `Stepper` | 按钮区定制 ≥44px |
| 输入框 `.input` | `Input` | 口令 type=password |
| 记一笔弹层 `.sheet` | `Popup` position="bottom" round | 遮罩点击=取消，不丢已选 |
| 骨架屏 `.sk-*` | `Skeleton` avatar/row | 形状照抄真实布局 |
| 空态 `.empty-box` | `Empty` + `Button` | 一句结论+出口 |
| 横幅 `.banner/.banner-warn` | `NoticeBar` 或自绘 | 错误必配重试 |
| 清单勾选行 `.item` | `Checkbox` + `Cell` | 已有=划线禁用态 |
| 底部固定栏 `.stickybar` | 自 sticky 容器 + `Button` | 最后操作按钮完全可见 |
| 沉浸大图 `.dhero` | `Image` + 自渐变遮罩 | 返回=44px 圆钮 |
| 反馈 Toast（已保存/没保存上） | `Toast` | 设计规则 2：禁止静默 |

## 5. 文案与行为红线（沿用旧 spec §5/§6 精神）
