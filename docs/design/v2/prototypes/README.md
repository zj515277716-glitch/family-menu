# 视觉方向原型 ×3（T-Q07）

3 套方向 × 3 关键屏（a 首页双区 / b 三餐菜单 / c 采购清单+备菜建议），静态 HTML，同一份示例内容（2 大 1 小 · 10月14日三餐），只换视觉语言。每套方向 1 个共享 CSS 变量组（`style-N/style.css` 顶部 `:root`：色板/字阶/圆角/阴影），换 token 即换风格；不引外部框架。菜品图位默认「占位色块 + 菜名 + 实拍图位」标注；方向① 已迭代配 AI 示意菜品图（`assets/dishes/`，11 张，页面标注「示意图·正式版为试做实拍」——正式版仍为试做实拍，DEC-007 口径不变）。

## 方向① 暖白极简（主控推荐，#C8541F）

- **配色**：米白底 #FAF6EF + 深棕字 #2C2420 + 暖陶橙主色 #C8541F（与 v1 番茄暖橙同源）；好评/必消用浅绿，中性标签用米灰。
- **字阶**：26/21/17/16/14/12.5 六级，正文 16px；标题 700 不加字距。
- **卡片语言**：白卡 + 1px 细线 + 近乎无阴影，分区靠留白与细线，圆角 8/12/16 偏利落。
- **与偏好表对应**：整洁清新✓（大留白、弱装饰）；分区明确✓（细线分区）；步骤统一✓（备菜序号圆点同一形式）；有食欲✓（暖橙点缀 + 暖色占位块）；不冷不卡通不呆板✓；长辈友好最强（高对比、按钮 48px）。

### ①的版式变体（配色/字阶 token 不动，只动版式与图片比例，2026-10-13 迭代）

- **v1 小图版**（`style-1/`）：初版，64px 图行。用户反馈「图片偏少偏小、没食欲、不够精美」，保留作对照。
- **v2 大图版 A · 杂志风**（`style-1/v2/`）：每餐头图 = 主菜大图通宽 16:9（圆角 --r-2、底部渐变遮罩压餐次名与「下一餐」等胶囊标签），同餐其余菜品 100px 中图行；图为主、字为辅，参考美食杂志排版；清单屏文字为主，分组标题右侧叠放 34px 小圆图点缀。
- **v3 大图版 B · 网格风**（`style-1/v3/`）：菜品卡上图下文（图 4:3 通宽卡顶、圆角上沿），卡内只留菜名 + 1 行关键信息，「换一道」收成卡底 40px 小按钮；b 屏双列网格，首页「今天三餐」每餐区横滑卡片流（真实 overflow-x）；清单屏同 v2 小圆图点缀。
- 两变体均：图加圆角/轻投影/渐变遮罩/标签胶囊去「贴图感」；保留①的大留白与细线分区；正文 ≥15px 等效、主按钮 ≥44px；示意菜品图增至 13 张（新增拌豆腐丝、米饭）。

## 方向② 和风暖木（#B07D4E）

- **配色**：米纸底 #F4EDE1 + 深褐字 #3A2C1F + 暖木褐主色 #B07D4E；占位色块降饱和走哑光木色。
- **字阶**：同①六级，标题加 0.05em 字距，呼吸感更强。
- **卡片语言**：奶油卡 #FFFCF5 + 更大圆角 12/18/24 + 柔和暖影，像木质食盒，分区靠卡片浮层而非细线。
- **与偏好表对应**：整洁✓、分区明确✓、步骤统一✓、温馨有食欲✓（暖木调）；风险：字色与线色偏浅，长辈辨识度中等（偏好表含不熟手机的长辈，故列为次选）。

## 方向③ 青瓷清新（降权照出，#4A9D8F）

- **配色**：青瓷绿主色 #4A9D8F，但页面底用暖中性米白 #F5F4EE、时间/提示点缀用暖橙 #D87E4A、占位菜品块沿用暖色系——三处暖手法弥补主色偏冷。
- **字阶**：同①六级，不加字距。
- **卡片语言**：白卡 + 浅青灰细线 + 清淡浅影，圆角 10/14/20 中等清爽。
- **与偏好表对应**：整洁✓、分区明确✓、步骤统一✓；偏好表明确「颜色偏冷、不太适合中式餐饮」，故按风格板结论降权，照出供对比；冷感已用暖底/暖点缀缓解，红亮菜品实拍图搭配仍需实机看效果。
