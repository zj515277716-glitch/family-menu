## 一、信息架构总览

```
登录门（login，进门一次口令，免登录设备自动进首页）
└── 底部 3 个常驻 Tab（NutUI Tabbar，reLaunch 切换清栈）
    ├── Tab1 首页 ── 默认落地页：上半区「今天」+ 下半区「定明天的餐」
    ├── Tab2 历史 ── 按日分组，每天展开早/中/晚三餐 + 每餐评价标签
    └── Tab3 设置 ── 长期生效项（含新增的「已吃菜避开窗口」）

首页出发的 4 个流式子页（navigateTo 推入、不占 Tab 位）：
    ├── 定明天的餐（meal-setup）——人数(成人/儿童)/必消/临时忌口/想吃/餐次勾选
    ├── 三餐菜单（meals）——早中晚分区 + 必消横幅 + 换一道/换一餐/全部换一批
    ├── 采购清单 + 备菜建议（shopping）——三餐合并去重一次买齐 + 今晚预处理/明早先做
    └── 菜品做法（dish）——沉浸大图 + 用料按人数缩放 + 分步（首页/历史/菜单页均可进入）

「记一笔」：当天每餐卡上的轻量弹层（按餐三问，不占页面、不漏评不追）
```

**双周期在一张首页上的落法**：

| 时间 | 你在首页看到什么 | 干什么 |
|---|---|---|
| 第 N 天晚上 | 上半区：今天三餐（含已记评价标签）；下半区：「定明天的餐」入口（或已定摘要） | 点下半区 → 设置 → 生成三餐 → 审/换 → 确认 → 采购清单 |
| 第 N+1 天白天 | 上半区：今天三餐（按当前时间「下一餐」置顶）；下半区：可顺手定后天的餐 | 点菜看做法；做完一餐点「记一笔」弹层 |

## 二、3 个 Tab 各放什么（「我的东西在哪」速查）

### Tab1 首页 — 「今天吃啥、明天定啥，全在这」
| 内容 | 位置 | 对应条款 |
|---|---|---|
| 今天三餐（早餐/中餐/晚餐卡，下一餐置顶） | 首页上半区 | C-5 |
| 某道菜做法 | 点餐卡 → 做法页 | C-5 |
| 做完一餐「记一笔」（做了没/好吃吗/下次还做，耗时选填） | 餐卡上弹层，按餐独立 | C-5 |
| 定明天的餐（人数/必消/临时忌口/想吃/餐次） | 首页下半区入口 → meal-setup | C-2 |
| 明天三餐（已生成时显示摘要，可再调整） | 首页下半区 → meals | C-3/3a |
| 换一道 / 换一餐 / 全部换一批 | meals 页 | C-3a |
| 明日采购清单 + 备菜建议 | meals 确认后 → shopping；明天已定摘要区也有直达 | C-4 |
| 服务未连接横幅（可重试） | 首页顶部（全局） | 总则 |

### Tab2 历史 — 「过去吃过的三餐都在这」
| 内容 | 位置 | 对应条款 |
|---|---|---|
| 按日查看过去三餐 | 历史主页，按日分组展开早/中/晚 | C-6 |
| 每餐评价标签（做了好吃/一般/翻车/没做） | 每餐卡上 | C-6 |
| 历史某道菜做法复看 | 点菜品 → 做法页（复用） | C-6 |

### Tab3 设置 — 「长期生效的东西在这」
| 内容 | 位置 | 对应条款 |
|---|---|---|
| 默认成人/儿童人数、常做时长档 | 设置主页 | C-1 |
| 家里有的锅/厨具、喜欢的菜系 | 设置主页 | C-1 |
| 忌口（硬禁忌一票否决 / 软偏好） | 设置主页，红线提示 | C-1 |
| **已吃菜避开窗口（3/5/7 天，默认 7）** | 设置主页（PD-020 新增项） | C-1 |
| 冷启动引导（首次使用先填设置） | 首次进首页引导至此 | C-8 |

## 三、关键路径对照（与 PD-020 补丁 C-1~C-8 的映射）

| 条款 | 路径（本导航下） |
|---|---|
| C-1 长期设置 | Tab3 设置 |
| C-2 定明天的餐 | 首页下半区 → meal-setup |
| C-3 推荐三餐 | meal-setup「推荐菜谱」→ 骨架屏 → meals |
| C-3a 换一道/换一餐/换一批 | meals 页内（换一道为弹层） |
| C-4 采购清单+备菜 | meals「查看采购清单」→ shopping |
| C-5 当天执行+按餐记录 | 首页上半区 → dish / 「记一笔」弹层 |
| C-6 历史 | Tab2 历史 |
| C-7 空手场景 | meals 生成失败态（如实说明哪餐为何出不了+出路） |
| C-8 冷启动 | 首次首页 → 引导填设置 → 引擎无历史也能出餐 |

**结论**：三餐流程的全部条款都有明确落点；「我的东西在哪」一句话版——**今天和明天的事在首页，过去的事在历史，长期的事在设置**。

## 四、确认结果（2026-10-12 产品负责人 4/4 拍板）

1. **今天没定餐时**：上半区显示「去定明天的餐」引导（双区结构保持稳定，不隐藏）。
2. **「记一笔」用弹层**：餐卡上就地三问，不跳页、可稍后补。
3. **采购清单双入口**：meals 确认后自动进清单 + 首页「明天已定」摘要区「查看清单」直达。
4. **Tab 命名**：「首页 / 历史 / 设置」。
