# 视觉参考收集卡

请把 3–5 张你觉得好看、好用的 App 截图放进本目录（`docs/design/v2/references/`），文件名随意，然后填下表。截图可以来自任何类型的应用（菜谱、购物、政务、银行……），不必是同类产品。

| 截图文件名            | 应用名     | 我喜欢的地方                                 | 我不喜欢的地方             |
| ---------------- | ------- | -------------------------------------- | ------------------- |
| 1、清新食欲版          | 西餐类     | 画面整洁清新、分区明确、图片数量、比例合理                  | 商业性功能布局             |
| 2、清新版1；清新版2；清新版3 | 美食类     | 页面清新干净、布局合理整洁                          | 颜色偏冷、不太适合中式餐饮色调     |
| 3、简洁版1；简洁版2；简洁版3 | 食物热量记录类 | 页面简洁、能量条可视化更直观、滑块选项卡更生动、交互跟顺畅          | 场景图片内容过少            |
| 4、整洁趣味版          | 食谱类     | 整体页面布局更贴合我的产品需求（同食谱类）、视觉诱人、步骤清晰、整体色调统一 | 过于卡通化，视觉有局限性（不够大众化） |

另外回答三个问题（一句话即可）：

1. 主要使用的人：一家人以及亲戚、朋友家庭试用（含不太熟手机的长辈、看清单买菜的人）
2. 一定要有的：步骤清晰、做法详情页要有统一的排版和表现形式，整体页面风格要统一
3. 一定不要的：页面布局杂乱、缺乏食欲感、视觉风格过于呆板

填好后告诉主控"参考已放好"，主控据此出风格板（docs/design/v2/）。
